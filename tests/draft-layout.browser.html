Geometria da seleção de jogadores

Teste de integração com o renderer, os dados, as folhas, o cabeçalho e o rodapé atuais do site. Cada caso abre em um iframe com resolução própria. São verificados overflow horizontal, sobreposição dos painéis, conteúdo do cabeçalho, linhas de pelo menos 60 px e campo sem cortes.

Execute npm run dev na raiz do projeto e abra http://127.0.0.1:4173/tests/draft-layout.browser.html. A resolução 1093 × 540 representa o espaço CSS aproximado de uma tela 1366 × 768 com zoom de 125% e barras do navegador.
