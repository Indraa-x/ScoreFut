# Futebol para montar. Uma carreira para construir.

O **ScoreFut** é um jogo de futebol para navegador criado por **[Indraa](https://github.com/Indraa-x)**. Assuma um clube no **modo Manager** ou combine jogadores de outras gerações para disputar as copas. Escalação, mercado e escolhas táticas dão forma à sua campanha.

**No celular e no PC · Temas claro e escuro · Progresso salvo no navegador · Sem cadastro**

## Assuma o comando

Escolha uma liga, assuma seu clube e construa a temporada dentro e fora do campo.

### Cinco ligas. Qual é o seu clube?

| 🇩🇪 Alemanha | 🏴 Inglaterra | 🇪🇸 Espanha | 🇧🇷 Brasil | 🇮🇹 Itália |
| :---: | :---: | :---: | :---: | :---: |
| **Bundesliga** | **Premier League** | **LaLiga** | **Brasileirão** | **Serie A** |
| 18 clubes | 20 clubes | 20 clubes | 20 clubes | 20 clubes |

Os elencos europeus usam a temporada **2026/27**, e o Brasileirão usa **2026**. Os clubes elegíveis já começam a primeira temporada com a Champions. Nas edições seguintes, o **G4 de cada liga europeia** define as vagas.

A classificação acompanha os resultados das partidas, com pontos, vitórias, empates, derrotas, saldo de gols e artilheiros com foto. As zonas de Champions, repescagem e rebaixamento aparecem destacadas na tabela.

### A resenha também entra em campo

Reúna **dois ou quatro jogadores no mesmo aparelho**, monte os times em sequência e dispute o **Desafio com amigos**. A chave tem ida e volta, com agregado, prorrogação e pênaltis para decidir quem avança. [Veja as regras](docs/CHALLENGES.md).

## O jogo em movimento

- **Campo animado** com os dois times, bola, gols e incidentes.
- **Ritmo normal ou rápido**, com opção de simular até o fim.
- **Pênaltis cobrança por cobrança** nas decisões.
- **Suspensão por vermelho** cumprida no próximo jogo da competição.
- **Conquistas e estatísticas** salvas no navegador, com resultado para baixar em PNG nos modos de copa.

A escalação, os OVRs e o estilo de jogo influenciam a simulação. Os resultados e o progresso da campanha são registrados no navegador utilizado.

## Rode localmente

Você precisa de uma versão atual do **Node.js**.

```bash
git clone https://github.com/Indraa-x/ScoreFut.git
cd ScoreFut
npm run dev
```

Abra **[http://127.0.0.1:4173](http://127.0.0.1:4173)**. O servidor usa os módulos do próprio Node.js e pode ser iniciado diretamente após clonar o projeto. Encerre com `Ctrl+C`.

<details>
<summary><strong>Desenvolvimento e estrutura</strong></summary>

<br>

O ScoreFut usa **HTML, CSS e JavaScript com módulos nativos**.

| Comando | Função |
| --- | --- |
| `npm run dev` | Servidor local |
| `npm run check` | Validação de sintaxe e dados |
| `npm test` | Testes das regras, elencos e simulação |
| `npm run prepare:site` | Preparação dos arquivos estáticos em `dist/` |

O GitHub Actions executa os testes, valida o projeto, prepara `dist/` e publica no GitHub Pages.

```text
assets/     Escudos, retratos, troféus e áudio
data/       Ligas, jogadores, épocas e referências
js/         Carreira, mercado, draft e simulação
css/        Interface, temas e animações
tests/      Verificação das regras e dos dados
scripts/    Servidor, validações e preparação do site
docs/       Documentação do projeto
```
